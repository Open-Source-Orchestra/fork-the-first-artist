# Reach

Intended users are OSO stewards issuing invitations and artists checking claim state. OSO already has a source website and reusable profile design, but this repository has no verified active-user count or deployed Arkiv users. We do not infer adoption from repository availability.

The current Arkiv read feature is the steward's invitation/claim status CLI. An artist-facing signed claim journey is still being built. Testnet credentials and hosting are local/operator configuration, so we cannot yet claim the public can try the integrated feature.

After Mumbai, an artist claim UI, independently readable consent-approved public profiles, renewal monitoring, recovery, and operational ownership would be needed before shipping to the existing OSO community. This is a plan, not an asserted deployment commitment or user metric.
